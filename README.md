# Python Basic Projects

A collection of beginner-friendly Python projects created to practice Python programming concepts, error handling, functions, loops, conditions, lists, random numbers, and GUI development.

## 📌 Projects Included

### 1. Calculator
A simple calculator that performs basic arithmetic operations.

**Features:**
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles invalid integer input using `try-except`

### 2. Number Guessing Game
A game in which the computer randomly selects a number between 1 and 10.

**Features:**
- Generates a random number
- Accepts user guesses
- Displays whether the guess is correct
- Reveals the correct number if the guess is wrong

### 3. Stone Paper Scissors
A simple game where the user plays against the computer.

**Features:**
- Random computer choice
- Validates user input
- Detects a tie
- Determines the winner

### 4. To-Do List
A basic task management program for organizing daily activities.

**Features:**
- Add tasks
- View all tasks
- Exit the application
- Displays a message when no tasks are available

### 5. Digital Clock
A graphical digital clock built using Python's Tkinter library.

**Features:**
- Displays the current time
- Updates every second
- Simple graphical user interface

### 6. Expense Tracker
A basic application for recording and tracking expenses.

**Features:**
- Add expense names and amounts
- View recorded expenses
- Calculate total expenses
- Exit the application

## 🛠️ Technologies Used

- **Programming Language:** Python
- **GUI Library:** Tkinter
- **Built-in Modules:** `random`, `time`
- **Concepts:** Functions, loops, conditional statements, lists, tuples, exception handling, and user input

## 📋 Requirements

- Python 3.10 or later
- Visual Studio Code or another Python editor
- Tkinter for the Digital Clock project

Tkinter is included with many standard Python installations. On some Linux installations, it may need to be installed separately.
